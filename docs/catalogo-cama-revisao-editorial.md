# Revisão editorial do catálogo CAMA

Os dados de cadastro vêm do manifesto aprovado para planejamento. As descrições abaixo são propostas comerciais. As características visuais usam os nomes cadastrados e o inventário. Tons aproximados e capas ausentes exigem confirmação.

**Cuidados gerais propostos para revisão**

- Jogos de cama, colchas e cobre-leitos — conferir as instruções da etiqueta de cada peça do conjunto, quando aplicável.
- Edredons — seguir a etiqueta da peça e conferir se há orientação específica para o enchimento.
- Mantas e peseiras — consultar a etiqueta antes de definir o procedimento de limpeza.
- Protetores — consultar a etiqueta do protetor e as orientações de uso do fabricante.

As propostas acima ficaram fora do campo de cuidados. A etiqueta ou ficha técnica deve confirmar lavagem, secagem e demais procedimentos. A terceira foto do Protege é uma pendência complementar.
